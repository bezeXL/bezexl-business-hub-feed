# BezeXL OpenAI ürün feedi

Bu depo Ticimax XML verisini OpenAI Business Hub uyumlu CSV dosyasına dönüştürür ve GitHub Pages üzerinden yayınlar.

Gizli XML adresi kaynak kodunda tutulmaz. Depo ayarlarında `TICIMAX_XML_URL` adlı GitHub Actions secret'ı olarak saklanır.

Yayınlanan dosya: `openai-products.csv`
